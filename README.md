# AéroTech Maroc — Dashboard financier

Dashboard web GitHub Pages pour le reporting financier fictif d’AéroTech Maroc.

## Lancer en local
Ouvrir le dépôt puis, pour un serveur local statique :
```bash
python -m http.server 8000
```
Puis visiter http://localhost:8000/

## GitHub Pages
Dépôt : https://github.com/Zouzou1975/aerotech-dashboard
Application : https://Zouzou1975.github.io/aerotech-dashboard/

Le dashboard utilise les données du reporting Excel embarquées pour la démonstration. Depuis Chrome/Edge desktop, le bouton de liaison permet de sélectionner un fichier Excel local et la synchronisation surveille ses modifications.

Le fichier Excel source peut être ajouté à la racine ou dans public/data selon le besoin.
